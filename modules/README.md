# Steep Semantic Layer Modules

YAML files for metrics, dimensions, and entities. Use **Steep as code** to populate all metric definitions into a workspace.

**Quick setup:** Connect your workspace to the demo data source (tables already in BigQuery demo project), then run Steep as code with these modules to get all metrics in the workspace.

**Files:** `accounts`, `ad_spend`, `agg_arr`, `customer_features`, `customers`, `risk_events`, `subscriptions`, `transactions`, `visitors` (each has `metrics`, `dimensions`, `joinPaths`). Edit YAML to customize.
